# 设备与公开数据安全

1. 每台设备同一时刻只能有一个操作者。每条ADB/fastboot命令必须显式指定使用者自己的serial；不能把USB VID/PID当设备唯一身份。
2. 验证次序：只读 → RAM启动 → 写分区 → 修改bootloader状态。新候选使用新目录；失败证据冻结，不复用截断镜像、不自动盲重试。
3. 持久写入前完整备份相关分区，设备/电脑两端hash一致并有可用恢复材料。实时核实槽位和分区，不照抄其他设备的编号。
4. A/B槽只用bootloader支持的命令变更，不手写属性位或misc中的槽元数据。用户数据不格式化，未经备份不覆盖。
5. 长时间硬件实验前实际读取并检查电量。发布工具不得靠旧准入记录或自报布尔值绕过现场状态检查。
6. 不绕过固件认证、IOMMU、模块版本匹配或设备所有权门。STOP/CLOSE ACK、CPU响应排空和PAS shutdown返回0单独都不证明DMA停止。
7. vb2取消会把buffer归还用户；永久pin只能防free，不能防旧DMA写用户重用的内存。未知所有权时不能进入取消/free/reuse路径。
8. 序列号、MAC/蓝牙地址、校准、个人网络配置、凭据、备份、原始日志只留使用者私有目录，不进公开Git或附件。

## 必须预留恢复入口

曾使用的隔离PID1失败后进入无限HOLD；无shell/adbd/IP服务、未实现远程reboot dispatcher，SysRq关闭，也没有已armed看门狗证据。手机在这种状态时，即使电脑可打开ACM也不能执行 `adb reboot bootloader` 或串口shell。

恢复入口缺失是该实验方案的限制。电脑端USB重新枚举不等于手机SoC重启；带电池的手机也不会因断USB必然重启。不得通过盲发BREAK/DTR、协议外字符串或无限重试声称恢复。

公开的隔离代码只供审查，在硬件运行前必须另行实现并验证独立、指定设备绑定的恢复方案；不能把重启/复位本身当逐buffer归还证明。本仓库不提供未经验证的远程恢复承诺。
