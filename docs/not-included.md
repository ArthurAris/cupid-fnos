# 未包含的材料

本仓库只公开经审查的源码与脱敏说明，不公开以下材料：

- 原厂视频/ADSP/WiFi等固件二进制、ROM解包、fnOS用户态及官方内核二进制。
- boot/recovery/根文件系统/设备树容器等镜像、分区备份和个人数据。
- token、密码、私钥、Cookie、设备唯一地址、序列号、校准/传感器配置、个人SSID。
- 原始串口/系统日志、录制、图片、测试输出、原设备准入/nonce和信任配置。
- 本机开发目录、历史Git对象、智能体会话与完整第三方源码克隆。
- 编译对象/模块/ELF/可执行文件、Python缓存。

历史面板命令提取表、字体等若无法核实相应公开许可来源则不发布。模型通用参数与每机校准是不同类别，但给提取数据自行加SPDX并不能证明再分发权。部分历史内核套件因此不完整，README不得把它说成完整可刷方案。

源码中调用固件加载器不意味着附带固件的再分发授权。使用者应自行合法取得匹配设备、版本和许可证的外部材料。

公开的source manifest使用相对路径与源文件hash；它只记录发布关联，不替代原设备hash/backup、实时ABI或物理来源验证。
